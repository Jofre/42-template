# conventions: no byte family -- the items reach only the harness's own functions, never the code under test
  One number per tree.
    * an empty tree           -> the subject fixes that count
    * a single node           -> whether a lone node is depth 0 or 1
    * unbalanced trees        -> a tree whose two sides differ in depth: which
                                 side does your answer describe?
    * off by one everywhere   -> every answer one away: does your count include
                                 the level each node itself sits on?
