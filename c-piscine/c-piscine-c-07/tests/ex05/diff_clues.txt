  A string and a separator set; the pieces are printed one per column.
    * leading or trailing separators -> those produce no piece at all: "There
                                 cannot be any empty strings in your array"
                                 (the subject, p.13)
    * runs of separators      -> a run is one boundary, not several empty pieces
    * an empty input          -> the array still has to exist, and still has to
                                 be terminated
    * the last piece missing  -> the end of the string is also a boundary
    * the array is right but unterminated -> what marks the end of the array
                                 itself, as opposed to the end of each piece
    * an empty separator set  -> the whole string is one piece
    * only strings holding a byte of 0x80 or more -> what makes a byte a
                                 separator, and whether a comparison sees
                                 that char as negative
