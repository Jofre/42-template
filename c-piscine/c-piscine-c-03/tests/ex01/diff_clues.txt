  This layer compares the exact int you return; the output table compared
  only its sign. n is a column of its own; read the divergence against it.
    * n == 0 diverges                    -> what two strings compare as when
                                            nothing is compared
    * only pairs that differ AFTER n     -> stopping late; the bound is a limit,
                                            not a hint
    * only pairs differing above 0x7f    -> whether char is signed here
    * strings shorter than n             -> the terminator ends the comparison
                                            before n does
    * the sign is inverted               -> when s1 is the greater string,
                                            should the result be positive or
                                            negative? (man strncmp)
    * the magnitude differs but the sign is right -> the value itself,
                                            which only this layer compares; put
                                            your number next to the expected
                                            one for the same pair: what in
                                            those two strings could produce the
                                            expected one? (man strncmp, NOTES)
