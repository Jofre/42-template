  Several strings and a separator; the joined result is printed as text.
    * size 0                  -> the subject states exactly what to return, and
                                 it is not NULL
    * a single string         -> the separator appears once too often; it goes
                                 BETWEEN, not after
    * an empty separator      -> a length computation that assumed it was not
    * the result is truncated -> how many bytes does the joined string hold,
                                 and how many did your code allocate for it?
    * the result is not terminated -> the byte allocated but never written
    * only inputs holding a byte of 0x80 or more -> whether a comparison in
                                          your loop sees that char as negative
