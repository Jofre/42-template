  Each line is nmemb, size, and what came back: zeroed (a block of nmemb x

  or NOTZERO (a block with a byte that is not 0).

                                         calloc returns when nmemb or size is 0?
    * a block (zeroed or NOTZERO) where NULL was expected -> what does
                                         nmemb * size give in a size_t when
                                         the true product is more than
                                         SIZE_MAX?
    * only blocks past 4096 bytes     -> does anything in your function depend
