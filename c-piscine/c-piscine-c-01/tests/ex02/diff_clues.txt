  Both columns are printed after the call, so read them as a pair.
    * both outputs equal one input     -> one input's value is in neither
                                          output: at which line of your code
                                          does it stop existing anywhere?
    * both unchanged                   -> the function is working on copies, not
                                          on what the caller passed
    * only equal values diverge        -> equal values read the same swapped
                                          or not, so a value was changed rather
                                          than moved: what does your code store
                                          that is neither a nor b?
