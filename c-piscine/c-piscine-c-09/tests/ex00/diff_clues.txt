  Each line is the two strings, as hex, then the SIGN of what ft_strcmp
  returned for them: -1, 0 or 1. Group the lines by the pair of strings.
    * only the SIGN is wrong  -> when the first string is the greater one,
                                 should the result be positive or negative?
                                 (see man strcmp)
    * pairs differing above 0x7f -> whether char is signed here, and how
                                 man strcmp says the bytes are compared
    * equal strings           -> the exit condition when both ends arrive
                                 together
    * prefixes ("ab" vs "abc") -> what is compared once one string runs out
