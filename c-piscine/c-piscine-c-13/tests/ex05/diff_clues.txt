# conventions: no byte family -- the items' bytes are read only by the harness's cmp_str, which btree_search_item is handed and calls
  The pointer returned is printed as which item of the tree it is (its
  index in the list, -1 for none of them), then the bytes it points at, or
  NULL.
    * an empty tree           -> the subject says what to return
    * an item at the root     -> is the root's own item ever compared? The
                                 subject names the order the tree is walked in
    * items that are absent   -> the walk has to end, and end with the stated
                                 answer
    * NULL wherever the reference found one -> what each call hands cmpf: is
                                 the reference you were given one of the two?
    * -1 where the reference has an index -> the pointer returned is not
                                 one of the tree's items: what does the
                                 subject say the function returns?
    * another index, the same bytes -> several items are equal: which of
                                 them does the walk the subject names meet
                                 first?
