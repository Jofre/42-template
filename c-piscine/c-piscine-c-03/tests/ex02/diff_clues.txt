    * one byte of the destination is lost -> the terminator of the FIRST string
                                            is the position to write at
    * an empty source diverges           -> a loop that cannot run zero times
    * the result is unterminated         -> the second terminator, the one you

    * the return column alone            -> what the subject says is returned
