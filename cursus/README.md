# cursus — the Common Core

This folder holds the Common Core's projects, grouped by milestone: one folder
per milestone, `Milestone_N/`, and inside it one folder per project, named
exactly as 42 names it. A project folder has the same shape as one of
`c-piscine/`'s: one `BUILD.bazel`, the subject beside it, and a page of its own.

| milestone | project | page |
|---|---|---|
| 0 | Libft | [Milestone_0/Libft](Milestone_0/Libft/README.md) |

Whatever a project turns in lives under its `deliverable/`, as everywhere else in
this repository; see `AGENTS.md` §0.
