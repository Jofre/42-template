    * every negative          -> the subject says what an invalid input returns:

                                 calls itself?
    * only large inputs       -> every answer here fits in an int: what does
                                 your code do differently as the input grows,
                                 and does anything it computes on the way to
                                 the answer not fit? (What C promises about
                                 each type's width: docs/testing.md, under
                                 ilp32.)
    * it never terminates     -> the base case is not reachable from every input
