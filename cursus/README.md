# cursus — the Common Core

This folder will hold the Common Core's projects, one folder per project, named
exactly as 42 names it: the same `<course>/<project>/` shape as `c-piscine/`.

How the projects are grouped inside it — by milestone, or not at all — is decided
when the first one, Libft, starts. 42 has regrouped these projects before, so the
grouping is kept out of the paths until it is needed.

Whatever a project turns in lives under its `deliverable/`, as everywhere else in
this repository; see `AGENTS.md` §0.
