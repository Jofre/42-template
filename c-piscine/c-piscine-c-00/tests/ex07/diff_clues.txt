  Which FAMILY of numbers diverges?
    * only 0                    -> the loop that peels digits never runs for it
    * every negative            -> the sign, or the digit that follows it
    * only INT_MIN              -> negating the value first; INT_MIN has no
                                   positive counterpart in an int
    * digits reversed           -> the order recursion unwinds in
    * one digit missing or extra -> the base case, off by one
